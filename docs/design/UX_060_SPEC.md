# 0.6 — apontamento visual com confirmação

Mantém o estilo Ledger. Novo painel flutuante no próprio chat: candidatos visíveis numerados, prévia verde, Usar esta área, Voltar, Escolher outra, Camada maior/menor para textos, Mover painel e Cancelar/Esc.
Não escreve em campos para descobri-los e não clica nos controles do site automaticamente. Nenhum conteúdo privado é copiado para logs/capturas: evidências somente na fixture.
Seletores sem identificação estável usam posição apenas como último recurso explícito, com aviso. A prévia não comprova extração futura: preservar teste autorizado e bloqueio de ambiguidade.
Não bloquear com “muito genérico”: mostrar uma seleção verificável e permitir ajustar a camada. Quantidade de regiões visíveis limitada para evitar travar páginas grandes.
Conexões salvas podem ser excluídas com confirmação, somente o cadastro/recibo local, sem apagar Chrome/conversas. Bloquear durante tarefa/API ativa e exigir autenticação local.
Perfis mostram diretório primeiro para distinguir Default/Profile N; não inventar correção de identidade a partir do nome do Chrome.
Aceite: confirmação obrigatória, desfazer/cancelar, sem envio, sem escrita, seleção de texto antes rejeitado; exclusão autenticada e cancelável; capturas do picker desktop/375px.
Limites: sem homologação pessoal no LMArena/conta do usuário; seleção gráfica não cobre iframes e shadow DOM isolados nesta etapa. Mostrar candidatos não torna seletores posicionais estáveis.
