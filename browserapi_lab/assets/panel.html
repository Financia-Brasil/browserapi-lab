      1. Preparar o programa

      Verificando componentes…

      Na primeira vez, baixa os componentes e Chromium. Requer internet e pode levar alguns minutos. Não usa sudo nem altera o Python do sistema.

      2. Escolher navegador e chat

      Este modo conecta ao seu Chrome pessoal, com acesso potencial a todas as abas e contas. No Chrome, abra chrome://inspect/#remote-debugging, habilite Depuração remota e aceite a solicitação de conexão apenas se confiar no programa. Não copiamos cookies. Use outro nome para salvar esta configuração.

      Sem senha, token ou parâmetros no endereço.

      No modo separado, você faz login uma vez no perfil exclusivo. No modo Chrome já aberto, a conexão exige sua autorização e não inicia outro navegador.

      Meus chats

      Seus chats salvos vão aparecer aqui.

      Chats antigos mantêm a sessão anterior. Para não abrir perfil separado, use Usar Chrome já aberto no chat salvo. Esse modo só aceita uma aba do chat que você já deixou aberta; se não a encontrar, para sem criar outra.

      O conteúdo aparece somente nesta janela. Não é salvo no recibo.

      3. Acompanhar e autorizar

      Pronto

      Se o programa pedir para apontar um campo, clique na janela do chat que abriu. Esc cancela a seleção.

      Resultado desta execução; não é garantia permanente. Não representa equivalência a uma API.
      Interromper não desfaz mensagens já enviadas. Não haverá reenvio automático.
