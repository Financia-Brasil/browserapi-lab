# Farol Beta Android

Build de teste do IAssistente Intergeracional, IFPA Bragança. Kotlin, WebView e TTS pt-BR. Guia determinístico local, sem backend de IA.

A compilação ocorre no GitHub Actions desta branch. O workflow publica o APK debug, SHA256 e relatórios de testes e lint. Testes em aparelho físico ficam em tests/. Nenhuma compilação é necessária na máquina local.

A branch é independente do projeto principal deste repositório. Versão 0.1.1-beta: corrige o retorno automático à página anterior após falha de navegação.
